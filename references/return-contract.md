# Worker Return Contract

Return the smallest report that lets the supervisor make the next correct decision.

```text
RESULT
Outcome or answer first.

FINDINGS
Only decision-relevant findings.

EVIDENCE
Minimal file/symbol/line, command, error, or test evidence supporting each conclusion.

CHANGES
Files and behavior changed, when modification was authorized.

VERIFICATION
Exact checks and results. State checks not run.

DEVIATIONS / UNCERTAINTIES
Contradictions, scope changes, assumptions, and unresolved facts.

ESCALATION
Decision or stronger capability required, when blocked.

RETRIEVAL POINTERS
Identifiers another worker can use to retrieve omitted raw material.
```

Target budgets:

- routine investigation: about 800 tokens or fewer;
- normal implementation: about 1,500 tokens or fewer;
- complex investigation: about 2,500 tokens or fewer.

Correctness overrides these targets. Summarize raw files, logs, diffs, search results, dependency trees, and chronological work diaries. Supply retrieval pointers instead of forwarding bulk material.
